# Phase-localization workflow

This directory is the reproducible record of the Pluto RX2 eight-way phase-localization
experiment. It covers the physical geometry, bounded RF capture, continuity proof, circular
phase aggregation, direct-model diagnostic, anchored frequency-slope inference, sensitivity
checks, and the retained 2026-08-25 result.

The primary result is deliberately stated as a sector estimate:

- TX1 anchor: `(-26.5, +315.7) mm` in board-centred coordinates;
- TX2 highest-density point: `(+276.3, +131.1) mm`;
- TX2 direction: `25.4 degrees`, with leave-one-frequency-out modes from `18.8` through
  `35.4 degrees`;
- TX2 radius: `305.8 mm`, but this is dominated by the `304.8 +/- 50 mm` radial prior; and
- retained-profile residual: `25.8 degrees RMS`.

This is not a calibrated centimetre-level position fix. The robust conclusion is that TX2 is
in the lower-right sector of the board-centred plane.

## Reading order

1. [Combined experiment report](phase-localization-experiment-report-20260825.md) presents the
   complete transmitter analysis and RX1 follow-up, with accepted results clearly separated
   from rejected diagnostics.
2. [Method](method.md) defines the setup, safety boundary, observables, and inference models.
3. [Retained run](run-20260825-b.md) records the exact capture inventory, quality results,
   diagnostics, position estimate, and limitations.
4. [Reproduction](reproduction.md) gives acquisition, immutable reanalysis, inference, and
   deterministic PNG commands.
5. [Data dictionary](data-dictionary.md) identifies the authoritative JSON fields and units.
6. [RX1 reference experiment](rx1-reference-20260825-a.md) records the coherent dual-RX
   follow-up and why its strict geometry model correctly produced no position fix.

The compact report snapshot and generated figure manifest live under `data/`. Raw CI16
captures, metadata, and full Monte Carlo particle files remain outside Git under the per-board
state directory. The snapshot records SHA-256 hashes of those retained sources.

## What each PNG proves

| Figure | Purpose |
|---|---|
| `fig01` | Physical board/antenna geometry, coordinate convention, TX anchor and TX2 sector |
| `fig02` | Planned condition order, 42/42 completion, and continuity totals |
| `fig03` | Measured double-relative phase profiles at all seven frequencies |
| `fig04` | Repeat scatter, analyzer standard error, valid masks, and accepted counts |
| `fig05` | Failure of the unconstrained direct-path model and the 2.458 GHz outlier |
| `fig06` | Anchored phase-versus-frequency fit after marginalizing fixed antenna intercepts |
| `fig07` | TX2 posterior geometry and the radial prior |
| `fig08` | Leave-one-frequency-out and systematic-floor sensitivity |

Every figure is generated by `scripts/render_localization_report.py`; none is manually edited.

The RX1 follow-up figures `fig09` through `fig11` are generated separately by
`scripts/render_rx1_reference_report.py`. They document acquisition integrity, the failed
cross-state model gate, and the rank-one identifiability limit without presenting an ungated
alias as a location.
